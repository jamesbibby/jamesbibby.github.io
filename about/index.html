About Me

Overview

Hi 👋 I’m (James) Bibby and I write code.

I write highly scalable web applications and services. I usually code in Go these days; sometimes in Java, JavaScript, Ruby, Python, or C. I usually store my data in Postgres and Redis; sometimes I use Dynamo, Mongo or MySQL.

I build software platforms on AWS (sometimes Azure or Google Cloud) managed with Terraform and Ansible, and my infrastructure is always code. I monitor platforms and applications with ELK / EFK, StatsD (Datadog) and NewRelic.

I like front-end development too, and almost always reach for React and Redux for front-end applications.
