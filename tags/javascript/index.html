API Gateway in a Cloudflare Worker

 Posted on February 18, 2019  |  5 minutes  |  939 words  |  James Bibby

I have been working on some CloudFlare Workers for a number of different things: serving SPAs from S3, adding special headers to certain requests, geo-redirection… and a question came up about our URL structure at work. We have a microservice architecture with domain based routing. service-a.site.com, service-b.site.com, etc. This is a pretty standard routing when using platforms like Kubernetes, Mesosphere, Swarm, etc, but it gets in the way of the performance enhancements offered by HTTP/2 persistent connections in modern browsers.
